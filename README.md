# ZICA Pune Portal

Software exams for ZICA Pune · Kothrud students.

- **Students:** `exams/` — sign in with Google, book an exam date, take the 50-question / 60-minute theory exam (camera on), see results and assignments.
- **Admin & faculty:** `exams/admin.html`.
- **Demo:** `exams/?demo=1` (sample data, no sign-in).

Questions, answers and student data live in a private database and are never part of this repository.
